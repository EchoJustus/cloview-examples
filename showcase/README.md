## Adding your app

Open a pull request that adds one row to the table:

- **App:** its name, and the author or organisation.
- **What it does:** one sentence, plus what it shows about cloview (a `:ui/native`
  widget, a backend in another language, the licensing module, …).
- **Hosts:** which of JavaFX, WPF and Flutter it ships on.
- **Licence:** the app's own licence. Open source and closed source are both welcome.
- **Link:** the repository or the product page; a screenshot link is welcome too.

Rules:

- The app uses cloview-core's modules and is reachable at the link.
- An entry is a link only. The app keeps its own licence: the MIT licence of this
  repository covers the entry's text, not the linked app.
- No affiliate links or tracking parameters. An entry whose link stops working may be
  removed.

Would you rather contribute the app's code as an example in this repository? See
"[Adding an example app](../README.md#adding-an-example-app)" in the README.
